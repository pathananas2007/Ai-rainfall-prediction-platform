TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Render Backend not starting?
   → Check all 4 environment variables are set
   → Check build logs in Render dashboard
   → Try redeploy

Vercel Frontend not loading?
   → Check VITE_API_URL is set
   → Press F12, check browser console for errors
   → Try redeploy

CORS error in console?
   → FRONTEND_URL not set in Render
   → Set it and wait for Render redeploy (3-5 min)

Cannot connect to MongoDB?
   → Check MONGO_URI is exactly correct
   → Go to MongoDB Atlas, verify cluster is running
   → Check IP whitelist allows Render

"Module not found" error?
   → Backend requirements.txt not installed
   → Check Render build logs
   → Try redeploy


TESTING ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

Test Backend:
   GET /api/health
   Expected: {"status":"ok"}

Register User:
   POST /api/auth/register
   Body: {"email":"test@example.com","password":"Test@123","confirmPassword":"Test@123"}

Login User:
   POST /api/auth/login
   Body: {"email":"test@example.com","password":"Test@123"}
   Returns: token (store in localStorage)

Make Prediction:
   POST /api/predict
   Header: Authorization: Bearer TOKEN
   Body: {"temperature":25,"humidity":65,"windSpeed":10,"pressure":1013}
   Returns: {"rainfall":45.2,...}

Get Predictions:
   GET /api/predict/history
   Header: Authorization: Bearer TOKEN
   Returns: Array of predictions
