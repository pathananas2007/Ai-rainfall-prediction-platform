================================================================================
                        TROUBLESHOOTING
================================================================================

If backend won't start:
  - Check all 4 Render variables are set correctly
  - Check Render build logs
  - Try redeploy

If frontend won't load:
  - Check VITE_API_URL is set in Vercel
  - Press F12, check browser console for errors
  - Try redeploy

If CORS error:
  - FRONTEND_URL not set in Render
  - Set it and wait for Render to redeploy (3-5 min)

If can't connect to MongoDB:
  - Check MONGO_URI is exactly correct
  - Go to MongoDB Atlas, verify cluster is running
  - Check IP whitelist
