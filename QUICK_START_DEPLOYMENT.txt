3-STEP DEPLOYMENT
═════════════════════════════════════════════════════════════════════════════

STEP 1: MONGODB ATLAS (5 min)
  1. Go to: https://www.mongodb.com/cloud/atlas
  2. Create cluster (M0 free)
  3. Create user: rainai_user
  4. Get connection string
  5. Copy: mongodb+srv://rainai_user:PASSWORD@...

STEP 2: RENDER BACKEND (5 min)
  1. Go to: https://render.com
  2. Create Web Service
  3. Select backend folder
  4. Build: pip install -r requirements.txt
  5. Start: gunicorn app:app
  6. Add Env Vars:
     - MONGO_URI = [from step 1]
     - JWT_SECRET_KEY = [generate random 32 chars]
     - ENV = production
  7. Deploy
  8. Copy URL: https://rainai-backend-xxxxx.onrender.com

STEP 3: VERCEL FRONTEND (3 min)
  1. Go to: https://vercel.com
  2. Create Project
  3. Select frontend folder
  4. Add Env Var:
     - VITE_API_URL = [Render URL from step 2]/api
  5. Deploy
  6. Copy URL: https://rainai-xxxxx.vercel.app

STEP 4: FINALIZE (2 min)
  1. Go back to Render backend
  2. Set: FRONTEND_URL = [Vercel URL from step 3]
  3. Redeploy

TOTAL TIME: ~15 minutes

COMMON ERRORS & FIXES
═════════════════════════════════════════════════════════════════════════════

"Can't reach API"
  → Check VITE_API_URL in Vercel
  → Check Render backend is running
  → Visit /api/health to test

"CORS error"
  → Check FRONTEND_URL is set in Render
  → Wait for Render redeploy after setting it

"Database connection failed"
  → Check MONGO_URI is correct
  → Check IP whitelist in MongoDB Atlas
  → Verify username/password

"JWT token not working"
  → Clear localStorage and login again
  → Check Authorization header is sent
  → Verify token format: "Bearer TOKEN"
